# Weda

Frontend de Weda — plataforma para organizar casamientos (lista de regalos, RSVP y
micrositio). Ver [docs/FRONTEND.md](docs/FRONTEND.md) para la documentación completa.

## Correr localmente

**Prerequisito:** Node.js

1. Instalar dependencias:
   `npm install`
2. Levantar el servidor de desarrollo:
   `npm run dev`
